🎯 HOW TO USE REAL-TIME BILL PREVIEW:

Step 1: ADD ITEMS TO CART
  - Browse shop
  - Click products
  - Adjust quantities
  → Preview updates automatically on right side

Step 2: SELECT PAPER SIZE
  - Look at right panel "Live Preview"
  - Click paper size button
    • 58mm (smallest)
    • 80mm (standard) ← RECOMMENDED
    • A4 (large)
    • A5 (medium)
  → Preview instantly changes width/format

Step 3: CHOOSE FONT STYLE
  - Click Font dropdown menu
    • Standard (clean, POS-like)
    • Modern (contemporary)
    • Classic (formal)
  → Preview font changes instantly

Step 4: CHECK PREVIEW
  - See exactly how bill will look
  - See all items on final receipt
  - See totals and taxes
  - See if everything fits on paper
  → NO SURPRISES WHEN PRINTING! ✓

Step 5: PROCEED TO PAYMENT
  - Enter customer name
  - Select payment method
  - Enter payment details
  - Click "Proceed to Payment"
  → Shows payment form

Step 6: COMPLETE PAYMENT (ULTRA-FAST)
  - Click "Complete Payment"
  - Processing: 500ms ⚡
  - Order created instantly
  → Ready to print!

Step 7: PRINT RECEIPT (<0.5 seconds)
  - Click "Print Receipt"
  - Uses your selected paper size
  - Uses your selected font
  - Print dialog opens instantly
  → Receipt prints to thermal printer or PDF

Step 8: DOWNLOAD PDF (OPTIONAL - 1-2 seconds)
  - Click "Download Receipt"
  - Saves as: receipt-[ORDER_ID].pdf
  - High quality PDF
  → File saved to Downloads folder

🎯 TROUBLESHOOTING:

Q: Preview not showing?
A: Click "Show" button in Live Preview panel
   Make sure cart has items

Q: Paper size not changing?
A: Click the paper size button (bright blue = selected)
   Preview updates instantly

Q: Font not changing?
A: Use Font dropdown menu
   Select Standard, Modern, or Classic

Q: Bill looks cut off?
A: Check paper size width
   Smaller paper = narrower format
   Try 80mm if 58mm too small

Q: Print dialog not opening?
A: Check browser popups
   Allow popups from localhost:3000
   Some browsers block print windows

Q: PDF not downloading?
A: Check browser download settings
   Check if file appears in Downloads
   May take 1-2 seconds
