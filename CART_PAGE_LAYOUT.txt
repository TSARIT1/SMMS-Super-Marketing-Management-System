Step 1: Add Items to Cart (Left Column)
  → Live Preview INSTANTLY updates
  → Shows all items on receipt

  → Select 58mm for compact
  → Select 80mm for standard
  → Select A4 for large

  → Select Standard for POS look
  → Select Modern for clean style
  → Select Classic for formal
  → See preview change instantly

Step 4: When Satisfied with Preview
  → Click "Proceed to Payment"

Step 5: Complete Payment (500ms) ⚡
  → Click "Complete Payment"
  → Order created instantly
  → Preview shows "✓ Order Created!"

Step 6: Print Receipt
  → Uses same paper size you selected
  → Uses same font you chose
  → Prints exactly like preview!
