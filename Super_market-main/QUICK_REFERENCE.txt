┌─ TROUBLESHOOTING ─────────────────────────────────────────────────────────────┐
│                                                                               │
│  Containers won't start:                                                    │
│    → Check logs: docker-compose logs backend                                │
│    → Verify ports available: netstat -ano | findstr :8080                   │
│    → Rebuild: docker-compose build --no-cache                               │
│                                                                               │
│  Port already in use:                                                       │
│    → Change ports in .env or .dockerignore                                  │
│    → Kill process: taskkill /PID <PID> /F                                   │
│    → Use different port: BACKEND_PORT=8081 FRONTEND_PORT=3001              │
│                                                                               │
│  Out of memory:                                                             │
│    → Increase Docker memory (Settings → Resources)                          │
│    → Reduce JVM heap in docker-compose.yml                                  │
│                                                                               │
│  Database connection failed:                                                │
│    → Check MySQL health: docker-compose ps mysql                            │
│    → Verify credentials in .env                                             │
│    → Restart MySQL: docker-compose restart mysql                            │
│                                                                               │
│  Frontend shows blank page:                                                 │
│    → Clear browser cache (Ctrl+Shift+Delete)                                │
│    → Check console (F12) for errors                                         │
│    → Verify API_BASE_URL in .env and nginx.conf                             │
│                                                                               │
└─────────────────────────────────────────────────────────────────────────────┘
